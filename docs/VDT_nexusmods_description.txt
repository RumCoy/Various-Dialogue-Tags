Intended as a niche mod for those with multiple dialogue and relationship mods—originally meant to help keep track of which "Hey there!" is associated with the mod you wanted to use. Now, if you're not bothered by [b]dialogue tags[/b], VDT will let you know which mod is presenting which dialogue option. Inspired by KrisV777's [url=https://www.nexusmods.com/skyrimspecialedition/mods/135618]Dynamic Dialogue Replacer (DDR)[/url] and SkyHorizon's [url=https://www.nexusmods.com/skyrimspecialedition/mods/107676]Dynamic String Distributor (DSD)[/url], VDT dynamically adds tags to player dialogue options at runtime, avoiding the risks associated with editing plugins/ESPs.

Once a mod/source context has been established by an originating dialogue branch, VDT automatically stops repeating the same tag through its subsequent dialogue. The optional [b]"Immersive" Mode[/b] can further drastically reduce shown tags, only showing them when multiple different tags/mods are present in the same dialogue menu—this is for players who mainly want [color=#a4c2f4][b]tags when multiple mods are adding options to the same menu, but otherwise prefer mod-added dialogue to blend in naturally[/b][/color] (without any tags).

By default, VDT only tags mods explicitly supported by the curated built-in list, by the [b]User Config[/b], or by user-created [b]VariousDialogueTags_*.ini[/b] files. The UserConfig also allows you to [color=#a4c2f4][b]automatically tag every mod-added dialogue option[/b][/color] (this is disabled by default). Alternatively, [url=https://www.nexusmods.com/skyrimspecialedition/mods/120352]SKSE Menu Framework[/url] allows you to control the presence of tags (including auto-generated tags and "Immersive" Mode) without manually editing the Config file.

[center][img]https://staticdelivery.nexusmods.com/mods/1704/images/63625/63625-1676996774-1699634888.png[/img][/center]
VDT is an SKSE plugin, with [url=https://github.com/RumCoy/Various-Dialogue-Tags]source code available on GitHub[/url]. While it comes with its own curated built-in list of 800+ mods, players can override, change, or otherwise add additional mods via [b]VariousDialogueTags_UserConfig.ini[/b]. For the best update-safe method of adding custom plugin entries, create a file named [b]VariousDialogueTags_*.ini[/b], replacing * with any name you want.

[b][color=#a4c2f4]Automatic tags for any and every mod are now available![/color][/b] An option for players trying to trace a particular line, or for those who don't care about having only curated tags: VDT now allows mod dialogue options to be automatically tagged with the mod's plugin name if a curated/user-defined tag does not already exist. This option is disabled by default. Navigate to [i]SKSE\Plugins\VariousDialogueTags_UserConfig.ini[/i] and set [i]GlobalPluginNameFallback=true[/i] to enable. Alternatively (and easier-tively), [url=https://www.nexusmods.com/skyrimspecialedition/mods/120352]SKSE Menu Framework[/url] is now also natively supported—[url=https://www.nexusmods.com/skyrimspecialedition/mods/120352]SKSE Menu Framework[/url] is completely optional, but it will allow you to freely hide or show tags (automatically-generated or otherwise) while in-game.

[b][color=#a4c2f4]"Immersive" Mode is now also available.[/color][/b] Disabled by default—change via [url=https://www.nexusmods.com/skyrimspecialedition/mods/120352]SKSE Menu[/url] or User Config. When enabled, tags are hidden if all tags in a dialogue menu are the same; tags only appear when multiple different tags/mods are present in the same menu. This is for players who mainly want tags when multiple mods are adding options to the same menu, but otherwise prefer mod-added dialogue to blend in naturally. In practice, this largely hides tags for immersion-related mods such as [url=https://www.nexusmods.com/skyrimspecialedition/mods/32161]Serana Dialogue Add-On[/url], [url=https://www.nexusmods.com/skyrimspecialedition/mods/28905]More Dialogue Options[/url], or [url=https://www.nexusmods.com/skyrimspecialedition/mods/73363]More Ferries[/url], while still showing tags in menus where multiple mods/frameworks can be distinguished.

Minor [url=105799]Description Framework[/url] support is provided for ~20 mods. More information:
[spoiler]Slightly outside the scope of VDT (hence the spoiler), but aligning with VDT's general purpose: adding important explanatory text or indicators to otherwise ambiguous, generically-named "mystery" items. These items are otherwise description-less and somewhat obscure in their function. It's mostly immersive text subtly pointing to the related mod. A quick example: [i]"Material for Sidequest."[/i] descriptions added to [url=54245]Sidequests of Skyrim[/url] 'Shipment' misc items.

The included [i]aaaRumCoy_DESC.ini[/i] is set as low priority through both the ini (-99 priority) and filename priority (aa suffix); other Descriptions should consistently overwrite those provided here.

Added minor Description Framework support for roughly 20+ mods, including: AddItemMenu SE, Sidequests of Skyrim, Ruins Coins, Lux Via, Your Market Stall, Road Signs Fast Travel, Journeyman, Adamant, Mistborn, Fate Card Packs, Ebony Warrior Re-Imagined, Nessa, Skyshards Offer Skills, Torchbugs Expanded, and mods from other sites.
